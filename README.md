RompeCubos

Controles del Juego:

Flecha Izquierda / Derecha: Mover la paleta (Paddle) horizontalmente. 
Movimiento del Mouse Control alternativo para mover la paleta.
Barra Espaciadora (espacio): Lanzar la pelota (PingBall) desde la paleta para iniciar la jugada. 
Tecla M : Alternar dinámicamente entre el modo de control por Teclado y por Ratón.


Requisitos Previos:
1. Java Development Kit (JDK): Versión 11 instalada en tu sistema.
2. Gradle: El proyecto incluye el Gradle Wrapper (gradlew).
3. Eclipse IDE Java 2020 6 o superior.

Abrir y ejecutar el proyecto:
1. Abre Eclipse IDE.
2. apreta la opcion File y selecciona import.
3. Selecciona Gradle -> Existing Gradle Proyect y luego apreta next.
4. En Proyect root directory, haz clic en Browse... y seleccional la carpeta principal RompeCubos/.
5. clic en Finish. importa core y desktop.
6. En Package Explore, ve hasta RompeCubos-desktop/src/com/mygdx/game/DesktopLauncher.java.
7. Haz clic derecho en DesktopLauncher.java, Run As-> Java Application.
